# 角色強度、夥伴與家園機制說明文件 (Character, Partner & Home Mechanics)

本文件詳述《浪跡戰域》中影響角色強度的計算邏輯、夥伴的加成機制，以及家園建築的運作方式。

---

## 1. 角色總體強度計算 (Character Strength Logic)

角色的戰鬥能力由「有效數值」(Effective Stats) 決定，計算公式結合了基礎數值、裝備加成、夥伴加成以及神明系統的權重。

### 有效數值公式
*   **有效攻擊力 (Effective ATK)**：`(角色基礎 ATK + 總裝備加攻 + 總夥伴加攻) × 神明攻擊倍率`
*   **有效防禦力 (Effective DEF)**：`(角色基礎 DEF + 總裝備加防 + 總夥伴加防) × 神明防禦倍率`
*   **有效生命值 (Effective MaxHP)**：`(角色基礎 MaxHP + 總裝備加血 + 總夥伴加血) × 神明生命倍率`

### 神明系統加成 (God Stat Bonus)
根據當前啟用的神明（Active God）及其等級，獲得額外的百分比加成：
*   **天上聖母-媽祖**：提供防禦力加成 (`1 + 等級 * 0.5%`)。
*   **福德正神-土地公**：提供生命值加成 (`1 + 等級 * 0.5%`)。
*   **中壇元帥-三太子**：提供攻擊力加成 (`1 + 等級 * 0.5%`)。
*   **玄天上帝**：提供傷害 (Damage) 加成 (`1 + 等級 * 1.0%`)。
*   **關聖帝君-關公**：全方位加成（攻/防/血 各 `1 + 等級 * 1.0%`）。

## 2. 夥伴系統 (Partner System)

夥伴不僅直接參與戰鬥加成，還能在領地與經驗獲取上提供協助。

### 戰鬥加成 (Combat Contribution)
僅有「已上陣 (Deployed)」的夥伴會貢獻數值：
*   **輸出型 (DPS)**：貢獻 100% 戰力至攻擊力；其他類型夥伴僅貢獻 20%。
*   **坦克型 (Tank)**：貢獻 50% 戰力至防禦力；其他類型夥伴僅貢獻 10%。
*   **恢復型 (Healer)**：貢獻 100% 戰力至有效治療量 (Heal)；且與坦克型相同，貢獻 3 倍戰力至生命值上限。

### 經驗與成長
*   **戰場經驗**：戰鬥勝利後，所有「已上陣」夥伴均可獲得經驗值。
*   **女神恩典加成**：若商城道具「女神的恩典」生效，夥伴 EXP 獲得量增加 20%。

## 3. 家園建築系統 (Home Base System)

家園是金幣與建材的主要產出地，透過升級建築可提升產能。

### 建築種類與功能
*   **金礦場 (Gold Mine)**：持續產出金幣。
*   **素材營地 (Material Camp)**：持續產出「基礎素材」(Base Materials)。
*   **煉金坊/鍛造塢**：為功能性設施，隨等級提升可能解鎖更高階功能。

### 夥伴派遣加成 (Assignment Bonus)
每個建築可指派最多 2 名夥伴入駐，根據夥伴職業與稀有度提供加成：
*   **坦克型**：派駐於「素材營地」或「工坊」時，增加**建材產量百分比**。
*   **恢復型**：派駐於「金礦場」時，增加**金幣產量百分比**。
    *   *加成率*：傳說(R5): 5%, 優秀(R4): 3%, 普通(R3): 2%。
*   **輸出型**：不論派駐何處，均提供**升級消耗減免**。
    *   *減免率*：傳說(R5): 4%, 優秀(R4): 2%, 普通(R3): 1%。

### 升級公式
*   **時間花費**：`180秒 * (當前等級 ^ 1.8)`
*   **金幣花費**：`5000 * (當前等級 ^ 2.5)`
*   **材料花費**：隨等級指數成長，且受到 DPS 夥伴的減免影響。

## 4. 角色強度提升策略建議

1.  **裝備為重**：裝備提供的攻擊與防禦是後續所有百分比加成的基數。
2.  **神明修煉**：高等級的神明加成（特別是關公）能顯著放大角色的各項數值。
3.  **夥伴職責分配**：
    *   戰鬥時派遣高戰力夥伴。
    *   離線或掛機時，將坦克與補師指派到營地與礦場以最大化資源收益。
    *   升級建築前，指派 DPS 夥伴進入該建築以節省升級成本。

## 5. PWA 推播通知系統 (PWA Push Notification System)

為了提升離線時的資訊獲取，遊戲實作了 PWA 推播通知功能，玩家可在「個人選單 > 推播設定」中獨立管理以下情境：

*   **啟用推播通知 (Master Toggle)**：總開關，開啟時會向瀏覽器請求訂閱憑證。
*   **玩家死亡 (notifyDeath)**：自動探索中 HP 歸零陣亡時發送。
*   **資源滿額 (notifyBuilding)**：家園建築（金礦、營地）產出達到儲存上限時發送。
*   **遭遇強敵 (notifyElite)**：在地圖上遇到菁英、首領或特殊天氣怪時發送。
*   **交通抵達 (notifyTransport)**：搭乘火車或載具到達目的地時發送。
*   **天空預警 (notifyWeather)**：進入雷爆或導致扣血的惡劣天氣（如雷雨、風暴）時發送。

### 技術實作細節 (Technical Implementation)
*   **後端集成**：訂閱資訊 (Push Subscription) 會同步至 Supabase 的 `profiles` 資料表中。
*   **觸發機制**：由前端捕捉特定事件後，發送授權請求至 Supabase Edge Function (`send-push`)，再透過 VAPID 協議發送至玩家設備。
