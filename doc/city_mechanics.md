# 城市特色與設施運作邏輯說明文件 (City Characteristics & Facility Mechanics)

本文件詳述《浪跡戰域》中各大城市的區域特色、專屬設施以及製作道具（鐵匠與煉金）的運作邏輯。

---

## 1. 城市概覽與區域特色 (Regional Overview)

遊戲地圖基於台灣地理，將區域劃分為北、中、南、東四大板塊，每個主要城市都有其獨特的發展重點。

| 城市名稱 | 代表色碼 | 核心發展特色 | 專屬產出材料 |
| :--- | :---: | :--- | :--- |
| **台北城** | 🔵 | 科技與兵器中心。重點發展**武器**與**科技種子**。 | 科技廢料、魔法玻璃 |
| **新北城** | 🫐 | 防禦重鎮。重點發展各類**重型盔甲**。 | 科技廢料 |
| **桃園城** | 🟢 | 守護之城。重點發展**頭盔**與防護裝備。 | 科技廢料 |
| **台中城** | 🟠 | 交通樞紐與山脈工藝。生產專屬的**中央山脈系列**。 | 高山鐵礦、神木枝枒、太古神木 |
| **台南城** | 🔴 | 古都與熔岩工藝。發展**靴子**與火屬性強化。 | 炎漠紅砂、熔岩紅砂 |
| **高雄城** | 🟡 | 海港與重工業。具備造船設備，重點在**海洋資源**。 | 海淵珍珠、炎漠紅砂 |
| **屏東城** | 🟠 | 國境之南。沿海探險與資源蒐集。 | 珊瑚碎片 |
| **台東城** | 🟣 | 靈石之鄉。產出純淨水晶與岩石。 | 玄武岩礦石 |
| **花蓮城** | 💗 | 靈脈與飾品。重點發展**飾品**與**生命種子**。 | 花東水晶 |

## 2. 設施功能與運作邏輯 (Facility Logic)

每個城市配置了不同功能的設施（Facility），玩家需抵達該城市感應半徑（通常為 2000 公尺）內方可互動。

### 鐵匠鍛造坊 (Blacksmith) ⚒️
*   **運作邏輯**：消耗「特定配方材料」與「金幣」來打造永久裝備。
*   **材料情報查詢**：鍛造介面右上角提供「材料情報」按鈕，點擊後可查看全台各區域專屬材料的取得管道與分佈。
*   **分工限制**：各城市的鐵匠具備不同的專業配方。
    *   **台北**：長劍系列 (Wood Sword -> Dragon Slayer)。
    *   **新北**：盔甲系列 (Leather Armor -> Dragon Armor)。
    *   **桃園**：頭盔系列 (Leather Helm -> Dawn Helm)。
    *   **台南**：戰靴系列 (Leather Boots -> Flame Boots)。
    *   **花蓮**：飾品系列 (Amulet -> Star Hourglass)。
    *   **台中**：中央山脈系列 (中央之劍、太古木甲、日月明珠)。

### 煉金試驗所 (Alchemy) ⚗️
*   **運作邏輯**：融合藥草、魔力寶石或區域材料產出消耗品。
*   **城市限定配方**：
    *   **台北**：製作「力量種子」(科技) 與「鐵壁種子」(光學)。
    *   **台南**：製作「力量種子」(熔岩強化)。
    *   **高雄**：製作「中型生命藥水」(深海精華)。
    *   **花蓮**：製作「生命之果」(水晶共振)。

### 驛站 (Station) 🚂
*   **運作邏輯**：支付金幣搭乘火車，進行城市間的長途快速移動。
*   **速度加成**：若持有加值道具「高鐵通行票」，移動時間減半且變更圖示。

### 客運碼頭 / 造船廠 (Dock / Shipyard) ⚓
*   **分布**：主要位於台中、高雄、花蓮。
*   **運作邏輯**：負責海上航線或特殊船隻設施相關互動（特定劇情或高等級移動需求）。

### 城鎮佈告欄 (Quest Board) 📋
*   **運作邏輯**：獲取該地區的城鎮任務 (City Quests)，完成後獎勵金幣與該區專屬財貨（如靈氣、科技碎片等）。
*   **伺服器端判定 (2026-03-06 正式營運修正)**：
    *   **擊殺任務 (Kill)**：為避免精確座標偏差，區域擊殺判定範圍已由 1km 擴大至該城市行政區對應座標半徑（如高雄任務放寬至緯度 23.2 以下範圍）。
    *   **收集任務 (Collect)**：採集任務已與 `secure_resolve_combat` 掉落物掛鉤，部分任務（如新北採集鐵礦石）可透過在正確區域戰鬥獲得。
    *   **週常與探險**：新增週常任務池，支援跨城市追蹤。
